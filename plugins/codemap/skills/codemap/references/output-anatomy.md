# Output anatomy

The generated `codemap.md` has six sections plus a footer. Each is intentionally
short so a cold-start subagent can read the whole file in one pull.

## 1. Header

```
# Codemap — <repo-name>
_Generated: <ISO-8601 UTC>_
_Auto-generated by the `codemap` skill. Regenerate when package boundaries change._
```

The timestamp is the **only** non-deterministic line in the file. Two
runs against an unchanged tree produce a byte-identical body.

## 2. Summary

Counts: package count, total source files (`.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`,
`.cjs` outside `node_modules`/`dist`/`build`/`.next`/`coverage`), and a
language breakdown (`ts=N, js=N`).

## 3. Workspace overview

A markdown table with one row per package: name (from `package.json#name`),
relative path, language (ts/js/mixed/unknown), file count, and description
(from `package.json#description` or empty).

Packages are sorted by name for determinism.

## 4. Entry points

One line per package showing the resolved entry. Resolution order:

1. `package.json#module`
2. `package.json#main`
3. `package.json#exports["."]` — string, or `default`/`import`/`require` of an object
4. `src/index.{tsx,ts,js}` then `index.{tsx,ts,js}` at package root

Falls back to `(none detected)` if none of the above resolve.

## 5. Cross-package dependency graph

Directed adjacency: `A → B` means package A's source files import from B's
package name (or `B/anything` subpath). Each edge shows an import count
(file-to-file count if the `impact` plugin is available, otherwise an
approximate hit count from the grep fallback).

Sorted by source package name; targets sorted by descending count then name.

## 6. External-dep highlights

For each package, the top-N (default 10) external dependencies from
`package.json#dependencies`, alphabetical. Skipped if `--no-external` is set
or if no package declares dependencies.

**Why alphabetical, not popularity-weighted?** Determinism. Two runs on the
same `package.json` must produce identical output.

## 7. Conventions / ownership

Pointers (not content) to:

- `CODEOWNERS` / `.github/CODEOWNERS` / `docs/CODEOWNERS`
- `OWNERS`
- Every `docs/architecture/*.md` (except `codemap.md` itself)

Empty section if none exist.

## Footer

```
Regenerate with: `./scripts/codemap.sh`
```

Plus a one-line note that the file is auto-generated.
